# 앱별 후보 타일

> 각 앱 저장소가 보드에 보낼 타일의 **후보**입니다. 고르는 것은 각 저장소 작업에서 합니다(넉넉히 적었으니 솎아내세요).
> 톤·형태 뜻은 [DESIGN.md](DESIGN.md) 3장, 데이터 형식은 [TILES.md](TILES.md).
> "기본"은 처음부터 보드에 보일지(`default`)의 제안입니다. 나머지는 '위젯 추가'에서 고르게 둡니다.
> 원칙: **이번 주 몇 권·몇 편 같은 거시 통계보다 "최근 흐름"**(지금 하는 것, 최근에 끝낸 것, 다음 차례)을 보여줍니다.

## 보드 자체 위젯 (board 저장소, 구현됨)

| 타일 | 톤·형태 | 크기 | 데이터 |
|---|---|---|---|
| 날씨 | type·num | 1x1 2x1 **2x2** 4x1 | Open-Meteo를 보드가 직접 불러옴. 위치는 위젯 설정 |
| 시간표 | type·list | 2x1 **2x2** | 직접 입력(`월수 09:00 강의 A`). 지금/끝남/남은 시간 계산 |
| 스포츠 | type·line | 2x1 **4x1** | TheSportsDB를 보드가 직접 불러옴. 팀 번호는 위젯 설정 |
| 가격 추적 | type·num | 1x1 **2x1** | 직접 입력(물건, 지금 가격, 목표 가격) |
| D-day | type·num | **1x1** 2x1 | 직접 입력(이름, 날짜) |

## 역 도장깨기 (`sub`)

| id | 타일 | 톤·형태 | 크기 | 기본 | 데이터 |
|---|---|---|---|---|---|
| `station` | 최근 역 + 룰렛 | plate | 1x1 2x1 **4x2** | ✓ | 최근 도장 찍은 역 이름·로마자, "3일 전 · 87 / 150역", 룰렛 후보(지금 뽑을 수 있는 역, 최대 50개) |
| `wish` | 가고 싶은 역 | plate | **1x1** 2x1 |  | 다음 후보 하나 |
| `count` | 진행률 | type·num | **1x1** 2x1 |  | 찍은 역 / 전체 |
| `line` | 노선별 진행 | type·cells | **2x1** 4x1 |  | 노선 하나의 역 칸 (노선이 많으면 가장 최근 노선) |

- 룰렛 결과는 기록이 아니라 '제안'입니다. 보드가 Life Hub에 보내면(P7 B5) 역 도장깨기 수신함에 출처 `board`의 `station_draw` 제안으로 들어갑니다. Hub는 앱이 공유한 '지금 뽑을 수 있는 역(pool)'에 있는 역만 받으므로, 룰렛 후보는 그 pool에서 골라야 합니다.
