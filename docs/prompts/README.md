# 저장소별 프롬프트

각 파일의 구분선 아래를 해당 저장소 작업 세션에 그대로 붙여 넣습니다. 앱 프롬프트는 같은 틀이고, 「이 앱에서 특히 볼 것」만 다릅니다.

| 저장소 | 파일 | 하는 일 |
|---|---|---|
| animan | [animan.md](animan.md) | AniMan 보드 타일 고르기 + 만드는 함수 + README |
| letterbookxd | [letterbookxd.md](letterbookxd.md) | 책장 보드 타일 고르기 + 만드는 함수 + README |
| potcast | [potcast.md](potcast.md) | potcast 보드 타일 고르기 + 만드는 함수 + README |
| elosorter | [elosorter.md](elosorter.md) | ELO Sorter 보드 타일 고르기 + 만드는 함수 + README |
| 업적 라이브러리 저장소 | [achievement.md](achievement.md) | 업적 라이브러리 보드 타일 고르기 + 만드는 함수 + README |
| sub | [sub.md](sub.md) | 역 도장깨기 보드 타일 고르기 + 만드는 함수 + README |
| kyeokyeoi | [kyeokyeoi.md](kyeokyeoi.md) | 켜켜이 보드 타일 고르기 + 만드는 함수 + README |
| food | [food.md](food.md) | PALATE 보드 타일 고르기 + 만드는 함수 + README |
| 일기 룰렛 저장소 | [diaryroulette.md](diaryroulette.md) | 일기 룰렛 보드 타일 고르기 + 만드는 함수 + README |
| life-hub | [life-hub.md](life-hub.md) | 보드 API 설계 문서(P7) 갱신 — **완료** |

프롬프트를 고치려면 `scripts/make-prompts.py`를 고치고 `python3 scripts/make-prompts.py`로 다시 만듭니다.
